# Sales Analysis SQL Project A collection of business SQL queries built on a retail sales dataset. Demonstrates skills in data cleaning, aggregations, joins, window functions, CTEs, and LAG/LEAD analysis. 
## Tools Used - SQL (SQLite) - Excel (dashboard built from query outputs) 
## Dataset Two tables: Orders (order_id, product_id, revenue, profit, month, region, category) and Products (product_id, product_name, category).
